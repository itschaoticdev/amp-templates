# Breakneck AMP Templates

Custom [AMP](https://cubecoders.com/AMP) Generic-module templates maintained by [Breakneck Hosting](https://breakneckhosting.com).

| Template | Game |
|---|---|
| `oblivion-mp` | [OB:MP](https://obmp.readym.io/) - ReadyM multiplayer for The Elder Scrolls IV: Oblivion Remastered |
| `wukong-mp` | [WukongMP](https://www.ready.mp/) - ReadyM multiplayer for Black Myth: Wukong |

## Use

In ADS: Configuration → Instance Deployment → Configuration Repositories, add `itschaoticdev/amp-templates:main`, then Fetch Latest.

Both need the .NET 10 runtime on the host (`dotnet-runtime-10.0` on Linux).
